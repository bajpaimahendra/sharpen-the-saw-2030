









### EC2 (Elastic Compute Cloud) ###############################################################################################
		=> Allows users to take virtual machines on rent in  the cloud.
		=> costing ->Pay as you consume model
	    => term in used -> ec2, ec2 instance , ec2 server, virtual machines
	    => EC2 is integrated with other services as S3, RDS and SQS etc.
	    => security -> provides through VPC(vitual private cloud)
	    => EC2 is regional service
	    => CloudFront is global service , related to caching the content near to the user. 

### EC2 offers following Storage Options to store your data
	1- EBS , is pesistace storage as SSD (use for database , install OS ). it is directly attach wtith ec instance. we can increse EBS(SSD Drive ) without restart ec2 start.

	2- ec2 instance store , is temp store as RAM. it directly attach with ec2 instance

	3- EFS , is shared file system , associated with  multiple ec2 instances

	4- S3 is not directly attache to ec2 but can easly intract to ec2 instances  (use for backup, store images and all type of objects) 

	Note : by default. When we create a Ec 2 instance, EBS (SSD drive) will be there  with the instance store (RAM) , depending upon type of ec2 (t1, t2 etc..)
